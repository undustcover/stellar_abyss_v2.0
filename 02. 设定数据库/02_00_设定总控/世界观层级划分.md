	-  终极反转：  
		- **灵能不是力量，是“系统接口”**
	-  关键词：  
		**“宇宙正在崩溃”**

- # L3 文明层（远古历史层） 
- 元序星蠕→灵能基因来源；人类联邦的分裂与“四大诅咒”；幽影之墙的来历与工作边界。
	- **揭示内容：**
		- 人类联邦遗产
		- 四大诅咒派系
		- 外星文明觊觎灵能基因
	-  第二次反转：  
		- **地球只是“资源点”**
	-  关键词：  
		**“人类只是遗民”**

- # L4 真像层 （地球级真像）
- 六合集市 APP 的真实目的、诱导机制、以及“异虫入侵/坐标暴露”这条暗线操盘者是谁。
	**揭示内容：**

		- 灵能 = 会暴露地球坐标
		- 幽影之墙存在
		- 六合集市在“诱导使用灵能”
    
	- 第一次反转：  
		-  **灵能者 = 客观内鬼**
		-  主角转变动机成立
	-  关键词：  
		**“力量本身是灾难”**

- # L5 异常层（可见冲突层） 
- 科技路线 vs 灵能路线的内部决裂；官方调查线（李铮视角位）；资本/组织/灰产对抗（陈法承接）。
	- **揭示内容：**
		- 使用某些商品会产生“异常现象”
		- 灵能者开始出现副作用/失控
		- 有组织在“猎杀/收容灵能者”
    
	-  但还不知道：
		- 幽影之墙
		- 外星文明
    
	-  关键词：  
		**“世界存在不为人知的异常”**

- # L6 层 表象世界：
  马木“绝对无知者→觉醒回响视界→建立巨企→追杀灵能者”的人物弧光；金手指铁律与玩法升级
	- **内容：**
		- 六合集市APP = 神秘黑科技购物软件
		- 主角 = 开挂创业者
	    - 灵能者 = “超能力者 / 异常人类”
    
	- **特点：**
		- 完全现实逻辑
		- 不出现宇宙、文明、基因这些词
    -  关键词：  
		**“这就是个爽文”**
