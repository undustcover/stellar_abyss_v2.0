







# 1. 道具
## 1.1 六合集市
- 表象：一个未知的购物app，界面粗糙简单，物品描述抽象搞笑，与用户灵魂绑定。
- 真像：六合集市本体是失落人类帝国 T6 遗产，熵潮孢群只是污染/寄生/劫持了部分前端功能。
- 目的：诱导地球人使用高维道具 -> 引发能量波动 -> 消耗地球防御系统【幽影之墙】 -> 暴露地球坐标 -> 【熵潮孢群】入侵。
- 原则：绝对不会与用户对话


# 2. 地球入侵原理

## 2.1 熵潮孢群为什么不直接入侵地球

- L1，坐标限制 :  熵潮孢群不知道地球的精确坐标，只能确定“某片星域存在资源点”。
- L2 成本限制:  T2.5 文明可以星际迁徙，但跨星系/远距离投放成本极高，不能盲目搜索。
- L3 幽影之墙限制:幽影之墙不是挡住入侵，而是让地球在灵能网络中“不可索引”。只有幽影之墙源能消耗殆尽地球才可能被发现。
